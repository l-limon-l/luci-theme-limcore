# v1.0.2

A fix release for the floating notifications (toasts).

## Notifications

- Toasts are opaque again. They were painted as a 5–15% translucent tint over
  `backdrop-filter: blur(12px)`, so the blur was doing all of the work of
  separating them from the page. Where a browser does not apply
  `backdrop-filter` — most mobile browsers, among others — nothing was left but
  the thin tint, and the page showed straight through the notification. Each
  variant colour is now mixed into the opaque card surface instead, so the
  colours are unchanged in both themes and no longer depend on the blur.
  Inline `.alert-message` blocks rendered inside a page are untouched.

- Stacked toasts no longer overlap. Their vertical position came from a fixed
  step per index — 4.5rem on desktop, 2.5rem on narrow screens — while a toast
  holding two lines of text is taller than that, so several notifications at
  once landed on top of one another. The stack is now laid out from the
  measured height of each toast plus a fixed gap, recomputed when a toast is
  added or removed, on window resize, and when a toast's own content changes
  size (the UCI status toast rewrites itself in place).
