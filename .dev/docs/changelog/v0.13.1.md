# v0.13.1

Sources were rolled back to the fork point and the visual work redone against
measurements from a live OpenWrt 25.12 router instead of guesses. See
`.dev/docs/DESIGN-RULES.md` for the twelve rules this release is checked
against.

## Layout

- Dropped the 720px cap on the content column. `#maincontent` is already bounded
  at 90rem, and the cap left 384px of that unused on a 2560px viewport while
  LuCI's own tables overflowed their container.
- An empty table of contents no longer reserves its gutter. Pages with fewer
  than two sections build no TOC, and reserving the space regardless cost
  another 304px of content width.

## Typography

- `word-break: break-all` is gone everywhere: table cells, DHCP lease rows,
  dynamic-list values and placeholders. It split every word at whatever
  character hit the edge, which shredded non-latin text ("Статический" wrapped
  as "Статическ / ий"). Replaced with `overflow-wrap: anywhere`, which breaks
  only words that genuinely do not fit.

## Tables

- Rows whose cells wrap to several lines now align every cell to the top,
  globally rather than as a `#wifi_assoclist_table` special case. Single-line
  rows are unaffected.

## Known regression

The Popover API work for dropdowns and modals that shipped in v0.13.0 was
rolled back with everything else and has not been redone yet. Dropdowns opened
inside a modal can still be clipped by the modal's overflow box. This is next.
