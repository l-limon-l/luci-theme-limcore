# v1.0.1

A fix release. Both faults were reproduced in a harness running this theme's
own stylesheet, instrumented rather than reasoned about, and re-checked after
the change.

## Dropdowns

- The Mode / Channel / Width dropdowns under **Network → Wireless → Operating
  frequency** open again. They could not be opened at all.

  That widget is the only place in LuCI that builds raw `<select>` elements and
  puts them inside `<label>`s, and a `<label>` forwards a click anywhere inside
  it to the control it labels. Pressing the theme's trigger therefore produced
  a second, synthetic click on the hidden `<select>` — a sibling of the wrapper
  rather than a child of it — which the outside-click handler read as a click
  elsewhere on the page. The panel was closed in the same tick the trigger had
  opened it. Instrumented: one trigger click, two click events, panel left
  closed. The hidden select can never be clicked deliberately, so its clicks
  are all of this kind and are now stopped before they reach the document.

- Selects that enter the DOM with no options yet are themed once they are
  filled. The replacement marked a select as handled before checking whether it
  had any options, so the re-run triggered by that very population skipped it
  for good. The same frequency widget inserts its four selects empty and fills
  them on the next turn, which is how both faults landed on one control.
